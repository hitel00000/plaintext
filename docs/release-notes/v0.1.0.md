# PlainText v0.1.0

Initial release of PlainText, a deliberately minimal Android plain-text editor.

### Features
- **Clean "Blank Canvas" Editor**: Borderless text canvas with comfortable typography (16sp / 24sp line height) and edge-to-edge layout.
- **Storage Access Framework (SAF)**: New, Open, Save, and "Save As…" file operations.
- **External Intent Support**: Open text files from external apps (`ACTION_VIEW`, `ACTION_EDIT`).
- **Share Integration**: Share document text via Android sharesheet and receive shared text (`ACTION_SEND`).
- **Monospace Font Toggle**: Switch between default system font and monospace font.
- **Word Wrap Toggle**: Toggle horizontal scrolling for log files and code.
- **BOM Sanitization**: Automatic UTF-8 BOM (`\uFEFF`) detection and removal.
- **Minimal Adaptive Icon**: Custom monochrome document icon design.
- **Ultra-lightweight**: Privacy-first with no ads, no analytics, no accounts, and R8/ProGuard shrinking.
