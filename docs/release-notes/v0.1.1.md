# PlainText v0.1.1

Maintenance and UX enhancement release introducing the Title Document Switcher and important stability fixes.

### What's New
- **Title Document Switcher**: Tap the top app bar title (`FileName.txt ▾`) to open a minimal bottom sheet and switch between multiple open documents without intrusive tab bars.
- **Multi-Document Session Management**: Create multiple drafts (`+`) simultaneously while keeping text, cursor position, and unsaved changes in memory.
- **Visual Scrollbar Indicator**: Added a subtle, dynamic vertical scrollbar when scrolling through long documents.

### Bug Fixes & Stability
- **Live Text Statistics**: Fixed an issue where the word and character counts remained frozen at `0 words · 0 chars`.
- **External File Saving**: Added persistable URI permission handling and smart save fallback to `CreateDocument` when editing read-only external files.
- **Scroll & Cursor Preservation**: Fixed cursor and scroll position resetting to the top when the soft keyboard appears or disappears.
