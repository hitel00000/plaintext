# PlainText v0.1.2

Feature and UX enhancement release introducing zero-dependency Markdown rendering, text file MIME filtering, and a polished Document Switcher.

### What's New
- **Markdown Preview Mode**: Seamlessly toggle between plain text editing and formatted Markdown rendering with support for headings, inline styling (**bold**, *italic*, ~~strikethrough~~, `code`, [links](url)), code blocks, blockquotes, lists, and dividers without external library overhead.
- **Filtered Document Open**: Standardized the SAF file picker to prioritize text-based MIME types (`text/*`, `application/json`, `application/xml`, `application/yaml`, `application/toml`, etc.), with an optional "Open Any File (*/*)" action in the overflow menu.
- **Enhanced Document Switcher UX**: Refined the Title Document Switcher bottom sheet with visual file extension badges (`MD`, `TXT`, `JSON`, `YAML`, etc.), real-time line/word/character statistics, active document outlines, and quick open/new document action shortcuts.

### Bug Fixes & Improvements
- **Preserved File Extensions on Save**: Fixed an issue where saving `.md` files resulted in `.md.txt` by implementing dynamic MIME type resolution based on file extensions.
- **Fast-fail File Storage**: Eliminated multi-step IPC retry delays when attempting to save read-only files, allowing instantaneous fallback to Save As.
- **BackHandler Integration**: Back gestures now intuitively exit Markdown preview mode before prompting for unsaved changes or switching documents.
